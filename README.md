# REVYU — Pomodoro Study Timer

REVYU is a simple and modern Pomodoro study timer designed to help students manage their study sessions, stay focused, and build consistent study habits.

## Features

* Pomodoro timer with 25-minute focus sessions
* Short break and long break modes
* Start, pause, and reset controls
* Session progress tracking
* Daily focus time tracking
* Task list
* Responsive design
* Clean and minimal interface

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Fonts

## Purpose

This project was created to practice front-end web development and JavaScript while developing a practical productivity tool for students.
